Hosted Demo

Distributed MLAT control plane, visualized.

This demo shows how a distributed receiver network can flow through receiver discovery, signal ingestion, multilateration runtime, storage, and API/dashboard output.

In the current hosted demo mode, aircraft motion and receiver discovery can run in simulation so viewers can understand the system shape without waiting on live external integrations.

What You’re Looking At
Receiver Registry Receiver identity and metadata are modeled as CKB-backed registry state.
Feed Transport The runtime supports simulation, websocket JSON, and command-bridge transport modes.
MLAT Runtime Correlation, position generation, storage, API, and dashboard all run as one integrated stack.
