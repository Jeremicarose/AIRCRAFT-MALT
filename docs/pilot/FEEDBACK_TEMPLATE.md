## Value and cost

Ask separately about portable identity, cross-network use, decentralized owner
control, verifiable history, revocation, provenance, wallet effort, and
integration effort. Do not combine them into one leading question.

- Which capability, if any, solves a problem you currently have?
- Which capability duplicates something your current network already does?
- What additional evidence would you need before integrating it?
- What part of the wallet or CKB workflow is not worth the cost?
- What would you do next without help from the maintainer?
