# Archive Policy

Obsolete proposals, weekly reports, completed implementation plans, duplicated
README files, social posts, and grant copy were removed during the 2026-07-31
repository audit.

Git history is the authoritative archive for those materials. Keeping stale
copies in the current tree made repository search return contradictory product
identities and completion claims.

Do not add historical planning documents here merely because they may be useful.
Retain a historical artifact only when it is required to reproduce a released
binary, transaction, benchmark, or architectural decision. Such an artifact must
have an owner, date, claim scope, and link from `EVIDENCE.md` or an ADR.
